# T198 I1 — a count band picked on a parameterized question is priced

**Defect.** A step with `params.item_noun` stores its answer under the key `_resolveIntakeChain` mints (`item_count_template::light bulbs`). Three readers turned an answer key into a price by reading `intake_modules` / the step with the stored key and found nothing: the formula-trigger loop and the fee loop of `computeUnifiedQuote`, and the `item_count_overflow_formula` branch of `applyPricingFormula`. So for 18 services (LED bulbs, high-ceiling bulbs, plaster / wall-hole / brick / wood-paneling / squeaky-floor repair, window draft / hardware / screen, dimmer / smart switch, GFCI / USB outlet, smart plug, Wi-Fi extender, router, cabinet adjustment) the band's minutes, fee and overflow formula were never priced; "5 or more walls" fell to the one-wall base, below the four-wall band (T147's defect (c), back). The ratchet and golden master answered under the plain key `item_count_template`, which resolved, so nothing saw it. #249 (G1) typed counts answered the minted key, so "price unchanged" in G1 was true only because the engine ignored the answer.
**Fix (qr.html, the owner).** One LOGIC function, `resolveAnsweredModule(svc, moduleKey)`: a plain key is `DB.intake_modules[key]` as before; a minted key is the resolved chain entry (the shared module with the step's own question and bands merged in). Read by the two loops; the overflow formula reads the bands from it for a minted key. No registry, no new table, no change to any authored value.
**The governing contract (precedence).** T154 ruled that LED's bands move the price ($20 / $35 / $50, then a per-unit *fee* model). T182 (later; the Operator, 2026-10-17: "the pricing time model seems correct") replaced a flat service's per-unit answer fee with the answer's minutes priced at `time_pricing` ($70/h, rounded to $5; added time of 30 min or more is a project estimate), and retuned the wall / floor minutes so the Operator's rule #80 ("n walls cost n x the base price") holds. T182 governs; the T154 *ruling* (the bands move the price) is kept, its middle figure is the T182 arithmetic: 15 min = $17.50, which rounds to $20, so LED 2-3 bulbs is $20 + $20 = **$40** (not $35). No new policy.
