# T198 S1 — a leak with no named fixture is answered, not ignored

**Defect (found by looking at the real page, not the engine).** Typing "water leak", "I have a leak", "leak", "my house is leaking" or "roof leak" produced **no response at all**, and the page threw `Cannot read properties of undefined (reading 'units')`. Cause: the plumbing category has a Diagnostic dynamic definition and an Install one but **no Repair one**; a repair request that names no fixture (so no group) therefore fell to the catastrophic fallback (a vetoed `legacy_flow` route with no `quantity`), and `sqAnalyze` read `route.quantity.units` unguarded. "Pipe leak" and "toilet problem" worked only because they name a group.
**Change (owner: the inline orchestrator in `qr.html`; first version failed the gate, see below).** (1) `resolveDynamicService` takes a `lastResort` flag, passed only by the last-resort category branch of entity resolution: a Repair request whose category has no Repair definition but has a Diagnostic one resolves to the Diagnostic (it asks which fixture). The rule lives in the one resolver; existing services' dynamic enrichment is untouched. (2) `catastrophicFallbackRoute` keeps the vetoed route's own quantity (already decided by the one resolver), so no route lacks one and `sqAnalyze` keeps seeding `S.qty` straight from `route.quantity.units`. (3) Data: the generic `leak` object gets an override so a leak named on an air conditioner is Window AC Repair (the window-AC object already had a "leaking" override, but the generic leak object outranked it).
**What the first gate run caught (44972757226).** My first version composed two resolver calls with `||` at the call site and guarded the read with `?.units ?? 1`: the arbitration detector (`verify_r-invariant-provenance_caller_composition`) and the charter rule R-INTAKE-QTYONCE (`verify_charter_rule_index_v2/v10`) rightly refused both. And "window air conditioner leaking", formerly blank, reached the plumbing diagnostic, which `verify_group_symptoms_one_derivation` rightly refused (an appliance must not be asked a plumbing question). All three are addressed above, not by editing those tests.
**After.** The leak phrasings show the on-site quote panel: "Answer a few more questions" (asks "Which plumbing fixture needs attention?": sink or faucet, toilet, shower or tub, garbage disposal, water line) or "Book an on-site diagnostic" ($85, credited toward repair). No page error. Faucet leak, leak under the sink and the other named-fixture routes unchanged; "window air conditioner leaking" is Window AC Repair.
